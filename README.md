# DogRolê

Plataforma web de matching social entre donos de cachorro, focada em playdate (passeio/encontro) e com um filtro leve e autodeclarado de interesse em cruzamento. Sem reprodução com verificação/marketplace e sem adoção — escopo definido na Fase 1 do projeto.

## Stack

- Django + PostgreSQL (SQLite em desenvolvimento)
- HTMX + TailwindCSS
- Leaflet.js (geolocalização)
- Mercado Pago (assinaturas dos planos pagos)
